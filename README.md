# Zine Skin

给 Cursor 换上你自己的壁纸 —— **背景图 + 主题色 + 半透明界面**，一次设置，全局生效。

![展示效果](https://raw.githubusercontent.com/do996icu/zine-skin/main/media/example.png)

## 功能

- **壁纸背景** — 本地图片或网络地址，可调模糊、缩放、位置
- **玻璃质感** — 侧栏与编辑器分别调节透明度，壁纸自然透出
- **主题色** — 一键换强调色，内置 **Skin Dark** 配色主题
- **可视化面板** — 点选即可，不用翻设置 JSON
- **可逆** — 关闭或卸载时自动还原，Cursor 升级后会重新应用

## 快速开始

1. 安装扩展并**重载窗口**
2. 颜色主题选 **Skin Dark**（推荐）
3. 打开 **View → Appearance → Theme**，或点状态栏的 **Theme**
4. 选一张背景图，调好透明度即可

命令面板搜 **Zine Skin** 可以直接换图、改主题色、查看状态或一键还原。

## 注意

- 壁纸需要写入 Cursor 安装目录，首次使用部分环境需以管理员身份运行。
- Cursor 自动升级可能覆盖补丁，若壁纸消失，执行一次 **应用皮肤** 再重载即可。
