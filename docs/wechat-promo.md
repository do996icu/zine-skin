# 你的 Cursor，也可以有一张壁纸

---

写代码的时候，屏幕里永远是一块黑底白字——久了，真的有点闷。

于是我做了一个小插件：**Zine Skin**。

它能给 Cursor 换上你自己的壁纸，再配上半透明的「玻璃」界面，侧栏、编辑器都能透出背景。一张图，整个工作台立刻有了氛围。

![效果展示](https://cdn.jsdelivr.net/gh/do996icu/zine-skin@main/media/example.png)

---

## 它能做什么

**换壁纸**  
本地图片、网络图片都行。模糊、缩放、位置都能调，铺满窗口也行，定点展示也行。

**玻璃质感**  
侧栏和编辑器的透明度分开调。想多透一点壁纸，就把透明度往下调；想字更清楚，再往上拧一点。

**主题色**  
强调色一键换，还内置了 **Skin Dark** 配色。不用再去翻一堆 JSON。

**可视化面板**  
菜单里点 **View → Appearance → Theme**，或者点状态栏的 Theme，点选就能改，不用记配置项名字。

**可逆、可还原**  
关掉皮肤或卸载扩展，会自动还原 Cursor 安装目录。升级后壁纸没了？执行一次「应用皮肤」再重载就行。

---

## 怎么开始（三分钟）

1. 打开扩展市场，搜索 **Zine Skin**（发布者 do996）
2. 安装后 **重载窗口**
3. 颜色主题选 **Skin Dark**
4. 打开 Theme 面板，选一张你喜欢的图，调好透明度

也可以直接打开商店页安装：

https://open-vsx.org/extension/do996/zine-skin

命令面板搜 **Zine Skin**，还能快速换图、改主题色、看状态、一键还原。

---

## 一点点提醒

- 壁纸会写入 Cursor 安装目录，部分环境首次使用需要管理员权限。
- Cursor 自动升级有时会覆盖补丁；壁纸消失时，跑一下「应用皮肤」再重载即可。

这些都是为了让壁纸真正「渗」进整个界面，而不是贴一张假背景。
